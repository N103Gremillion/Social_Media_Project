## Front End
- React with react bootsrap was use for most of the front end components.
- react router was use for routing between pages
- react-konva was used to create the goal graphs
  
### References
[React](https://react.dev/)
[Konva](https://www.npmjs.com/package/react-konva/v/16.5.2)

## Back End
- Node.js with Express handled the Api layer of the backend
- MySql was used to store textual information
- multer was used to store imgs on the backend
